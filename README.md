# Server Player Count

Server Player Count is a Farming Simulator 25 mod that shows the current player count directly in the HUD on multiplayer servers.

## Features

* Shows the current number of active players in the HUD
* Displays server capacity when available
* Adds a compact server status indicator
* Green status: no server-side Lua warning or Lua error detected
* Yellow status: server-side Lua warning detected
* Red status: server-side Lua error detected
* Adds an in-game settings option to reset the server status indicator
* Hides the HUD display automatically in singleplayer

## Current version

ModHub release: 1.0.0.0

## Notes

This mod is intended for multiplayer servers.
In singleplayer, the HUD display is hidden automatically if the mod was enabled there by mistake.

The server status indicator is based on detectable server-side Lua warnings and errors. Additional detections may be added later if log data can be evaluated more cleanly in-game.
